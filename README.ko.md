# Codex Switch

메뉴 막대에서 Codex 요청 계정을 선택하고 계정별 남은 한도를 확인하는 macOS 앱입니다. 기존 Codex 로그인은 유지합니다.

언어는 Mac의 언어 설정을 따릅니다. 한국어·영어를 지원하며, 그 외에는 영어로 표시됩니다. 날짜와 시간은 Mac의 지역 설정을 따릅니다. 언어 설정을 바꾼 뒤에는 앱을 다시 엽니다.

## 설치와 사용

macOS 14 이상과 ChatGPT로 로그인된 Codex 앱 또는 CLI가 필요합니다.

1. [Releases](https://github.com/zzunkie/codex-switch/releases)에서 Apple Silicon용 앱을 받아 응용 프로그램 폴더로 옮깁니다.
2. 메뉴 막대의 S 아이콘을 누릅니다.
3. **계정 추가**에서 다른 계정으로 로그인합니다.
4. 계정 이름이나 원형 선택 버튼을 누르고 **계정 라우팅**을 켭니다.
5. 새 Codex 요청을 보냅니다. ‘Codex 연결 대기’가 계속되면 Codex를 한 번 재시작합니다.

배포 앱에는 로컬 서명만 적용되어 있으며 Apple 공증은 받지 않았습니다. 실행이 차단되면 최초 실행 시도 후 **시스템 설정 → 개인정보 보호 및 보안 → 확인 없이 열기**를 사용할 수 있습니다. 직접 소스에서 빌드할 수도 있습니다.

## 표시와 전환

자체 색상표·테두리·호버 배경·수제 게이지를 제거하고 시스템의 기본 Liquid Glass 재질, 버튼, ProgressView, Menu, Toggle을 사용합니다. 불투명 메인 패널은 시스템 배경색을 사용하며 밝기 모드와 손쉬운 사용 설정을 따릅니다. 여러 모델의 한도는 기본 메뉴에서 확인합니다.

- 요청을 처리하는 계정의 한도 막대에는 시스템 강조 색상을 사용합니다. 한도가 적게 남으면 주황색이나 빨간색으로 표시합니다.
- 서버가 제공하는 한도 주기를 그대로 표시합니다. 주간 한도만 있으면 막대 하나, 5시간·주간 한도가 있으면 막대 두 개를 표시하며, 별도 모델 한도는 **모델별 한도**에서 펼칩니다.
- 계정 변경은 새 요청부터 적용됩니다. 진행 중인 응답은 기존 계정으로 마무리합니다.
- 인증 오류나 한도 소진 시 다른 계정으로 자동 전환하지 않습니다.
- **응답 확인**은 앱 실행 후 해당 계정의 모델 응답 완료를 실제로 관찰했다는 뜻입니다.
- 최초 자동 포커스 링은 표시하지 않으며 Tab 키로는 정상적으로 이동할 수 있습니다.

## 리셋권

계정 카드 아래에서 남은 리셋권 개수를 확인하고 **사용…**을 누릅니다. 대상 계정을 다시 조회한 뒤, 확인 창에서 **1개 사용**을 선택하면 해당 계정의 리셋권을 사용합니다. 취소가 기본 선택입니다.

새 리셋 요청은 기본 5시간 또는 주간 한도가 10% 이하로 남았을 때 가능합니다. 별도 모델 한도는 이 조건에 포함하지 않으며, 최종 사용 가능 여부는 서버가 판단합니다. 기존 로그인과 요청 계정 선택은 바뀌지 않습니다.

응답이 끊겨 결과를 모르면 **결과 확인**으로 같은 요청을 다시 시도합니다. 앱을 재시작해도 요청 번호를 유지해 중복 소모를 막습니다. 첫 요청이 전달되지 않았다면 이때 1개가 사용될 수 있고, 이미 처리됐다면 추가로 사용하지 않습니다. 사용 후 한도 조회가 실패해도 확인된 성공 결과를 실패로 바꾸지 않습니다.

최근 Codex 버전이 필요합니다. 개수가 미확인이면 Codex 업데이트 또는 새로고침을 시도합니다. 결과가 미확인인 동안에는 앱 데이터 폴더의 `reset-attempts.json`을 지우지 않습니다. 자동으로 리셋권을 사용하는 기능은 없습니다.

실제 계정의 개수 조회를 확인했으며, 소모 동작은 가상 계정과 테스트 서버로 검증합니다. 테스트를 위해 실제 리셋권을 소모하지 않습니다.

## 종료와 데이터

라우팅을 끄면 원래 `openai_base_url` 설정을 복원합니다. 앱을 종료했다면 Codex도 재시작해 복원된 설정을 읽게 합니다. 강제 종료된 경우 앱을 다시 열고 라우팅을 끄면 됩니다.

추가 계정과 복구용 설정 백업은 `~/Library/Application Support/Codex Switch/`에 저장됩니다. 기존 로그인 정보는 원래 저장소를 사용하고, 추가 계정은 각각 별도의 Codex 저장소를 사용합니다. 프록시는 `127.0.0.1`에서만 요청을 받으며 프롬프트, 응답 본문, 토큰은 로그에 기록하지 않습니다. 외부 서버 설치는 필요 없습니다.

## 지원 범위

macOS 26 이상에서 네이티브 Liquid Glass를 사용하며, macOS 27에서 UI를 확인했습니다. macOS 14/15는 일반 카드 재질로 표시합니다. 유리 재질 빌드에는 Xcode 26 / Swift 6.2 이상이 필요합니다. 화면 캡처나 별도의 렌더링 루프는 추가하지 않습니다.

OpenAI의 공식 앱이 아닌 독립적인 실험 프로젝트입니다. 기본 OpenAI provider를 지원하며 커스텀 provider, 프로필별 endpoint 재정의, 조직 관리 설정은 지원하지 않습니다. Codex의 내부 API가 바뀌면 호환성 수정이 필요할 수 있습니다.

Codex 화면에는 기존 계정의 요금제·한도가 계속 표시될 수 있습니다. 기존 계정이 완전히 소진됐을 때 Codex UI가 요청을 허용하는지는 검증하지 않았습니다. 선택한 계정의 모델 이용 권한은 그대로 적용됩니다.

## 빌드

Xcode Command Line Tools가 설치된 Mac에서 실행합니다.

```sh
git clone https://github.com/zzunkie/codex-switch.git
cd codex-switch
zsh build.sh
open "dist/Codex Switch.app"
```

Apple Silicon과 Intel에서 각 Mac의 아키텍처로 빌드합니다. 공식 Node 배포본을 내려받아 고정된 SHA-256 값으로 확인한 뒤 앱에 포함합니다. npm 패키지는 사용하지 않습니다.

```sh
"dist/Codex Switch.app/Contents/Resources/Runtime/node" --test Tests/*.test.mjs
```

자동 테스트는 임시 파일과 가짜 인증 정보, 로컬 서버만 사용합니다. 실제 계정이나 유료 요청이 필요하지 않습니다.
